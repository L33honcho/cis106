3. ### What is Virtualization?
* Virtualization is a technology that allows the users to create virtual, simulated environments from a single, physical machine. 

4. ### What is Virtualbox?
* Virtualbox is a cross platform virtualization application, meaning it allows the current computer to extend it's features to be able to run multiple operating systems through multiple virtual machines at the same time.

4. ### What is a virtual machine?
* A virtual machine is a virtual representation or emulation of a physical computer that uses software instead of hardware to run programs and deploy application. 

5. ### In the context of virtualization, what does the host machine and guest machine mean?
* The host machine is the underlying hardware that provides the computing resources such as processing power, memory, storage, netowrk and so forth.
* The guest machine are virtual workloads that are within the host machine and share the machines computing resources.

7. ### WHat is a firewall?
* A firewall controls what is and more importantly isn't allowed to pass through the ports. A firewall should allow very little traffic through the ports. 

8. ### What is SSH?
* The secure shell protocol is a method for securely sending commands to a computer over an unsecured network. It uses cryptography to authenticate and encrypt connections. It's often used for controlling servers remotely to manage infrastructure and transferring files. 

9. ### WHat is an IP Address?
* An IP address is a numeric label assigned to devices that use the internet to communicate. Devices that communicate over the internet or local netowrks share information to a specific location using the IP address.

10. ### What is a network mask?
* A network mask which is also known as subnet mask is 32-bit value in computer networking that splits the IPv4 into two, a network address, and a host address.
