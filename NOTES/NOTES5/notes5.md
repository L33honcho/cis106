## Question 1

### **ls**
* **Definition**
  * List directory content
* **Usage**
  * Used for listing the content og a given directory or file/directory itself.
**Examples**
  * List everything in long listing format
    * ls -la
  
### **pwd**
 * **Definition**
   * Print name of current/working directory
 * **Usage**
   * Displays the current working directory (where your currently working.)
 * **Examples**
   * pwd
  
  ### **cd**
  * **Definition**
    * Changes the current working directory. In other words, moves around you
  * **Usage**
    * If you want to go to your home directory 
    * cd ~
* **Examples**
  * Change to the downloads file
    * cd Downloads
   *Change from current directory back to home.
    * cd ../
